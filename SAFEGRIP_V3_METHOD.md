# SafeGrip v3 method — superseded

SafeGrip-v3 (v0.7.0) used a prior/evidence architecture with handcrafted excitation-controlled reliability. The v0.7 LiRA trust run showed that the excitation pathway could worsen point estimation even when the gate was monotone.

The proposal in historical v0.8.0 was **SafeGrip-CI**, documented in `SAFEGRIP_CI_METHOD.md`. It replaces handcrafted excitation authority with friction-conditioned counterfactual identifiability and candidate-consistency acceptance.
